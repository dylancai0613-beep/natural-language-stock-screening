# 固定意图试卷

这里的contracts是预写的填空题定义，不是让AI临时生成意图卡。

- `选股意图试卷.json`：整张固定试卷，登记全部题目、股票池和条件组合。
- `市盈率.json`等指标同名文件：对应题目的槽位定义、默认值、选择项、空答案和校验约定。
- `shared/`：执行结果、数据证据的技术格式，属于输出协议，不是填空题。
- `examples/`：保存实际校验器生成的填写前后样例。

## 读懂一份题目

| 字段 | 含义 |
|---|---|
| metric_id / label | 稳定的内部指标ID / 中文名称 |
| metric_file | 指向config/metrics下同名指标说明 |
| question | 预写的条件句；花括号是填空位置，不是动态生成题目 |
| slot_definitions | 每个空的名称、类型、必填规则、默认值和选项 |
| answer.active | 客户是否使用此题；false时无需填写 |
| answer.slots | 实际填空值，以及来自客户还是默认值、是否确认 |
| answer.validation | 运行时由后端计算，不能信任模型自报 |
| answer.validation_errors | 不通过的槽位、原因、需要追问的问题和选项 |

模板中的空答案永久保留，客户实际答案保存在服务端会话内存中。模型只能填值，不能改模板。新增题目要同时增加同名metrics文件，并登记进固定试卷。

## 默认值和确认

市盈率题预写TTM、低于、20倍作为产品默认。聊天层在客户未指定日期/股票范围时采用当前缓存日期和三只样本并说明；客户明确值优先。默认来源为default，不能冒充user_input。行业比较仍不支持，相关需求通过对话保留并询问。所有检查和补充均在后台进行，前端不展示试卷表单。

模板内的槽位初始为空；`createQuestion`只是复制既有题目并应用其预写默认值，不生成题目。`fillQuestion`填空，`confirmSlots`确认，`validateQuestion`校验，错误作为下一轮模型澄清的后台上下文；客户用自然语言补充。未选题返回通过仅表示跳过，不代表答案已经填写。

## validation和数据状态

validation=false：缺少条件、值不合法、存在冲突或尚未确认，由模型自然追问，请客户补充或选择。validation=true：只代表意图填写有效。是否能取到正确数据由另一层负责，不混进客户填写校验。

目前支持全部满足或任一满足，不支持混合嵌套逻辑、多条同指标条件、自身历史比较或多指标跨字段比较；这类需求必须保留为未映射并追问，不能简化后静默执行。日后可扩充预写题型及槽位。


## 问答使用方式

当前12份指标题目由每轮DeepSeek调用选择和填值。模型同时接收预写默认与数据能力，用客户能理解的语言解释并询问是否调整。后台只接受目录内的指标和槽位，客户确认后才锁定条件进入筛选工具阶段。净利润同比扭亏和单季度净利润同比增速改善是两份独立题目，不可互相代替；没有预写报告期就必须通过问答明确。
