# 当前架构：模型驱动问答，程序执行筛选

## 客户体验

前端只有对话和筛选结果。客户描述想找的股票，DeepSeek解释采用的默认理解，询问是否需要修改；客户可自然回复或选择模型本轮生成的选项。后台固定题目、槽位、validation和工具协议不进入客户操作流程。发送按钮↑，Enter发送，Shift+Enter换行；没有保存/载入入口。

例如“经营改善、估值合理、走势相对稳定”可以先使用已批准默认解释，再询问是否需要调整。客户改成“经营更关注利润，不是收入”时，模型应进一步区分扭亏、利润增速加快等含义，保留估值和走势条件。此处只是测试场景，回复文字和下一步选项由每轮模型生成，不是硬编码客户话术。

## 两阶段运行

第一阶段由conversation.cjs读取固定题库、默认解释、真实数据能力及近期聊天，使用chat-clarify.md调用DeepSeek。模型返回自然语言、动态回复选项和白名单条件更新；服务端校验并合并，记录来源和未解决要求。模型不可写validation/confirmed、修改指标定义或返回股票数据。客户明确数值优先；默认值标default，不能冒充客户原话。语义不明确与数据未接入是两个状态：前者继续问，后者允许明确保留并在结果中待核验。

第二阶段由客户明确确认触发。确认的是当前服务端条件；修改后必须重新确认，旧结果显示过时标记。model-screening.cjs复制并锁定条件，使用screening.md调用DeepSeek。模型实际发出get_snapshot、run_screen的tool_calls，服务端只执行这两个只读工具并回传结果，模型再依据证据解释。工具参数不能注入条件、代码或路径。没有真实run_screen调用就不能返回成功结果。循环最多4次模型请求，不自动重试。

计算来自evaluator.cjs，不让模型算或虚构行情。模型回复不替代前端确定性结果表；解释与证据引用经过结构检查，真实字段、样本和日期限制均保留。

## 固定指标与数据

metrics说明指标含义、公式、数据来源和预写默认；contracts说明允许填写的字段、类型、选择项和默认值。12份指标按中文同名文件存放，固定题库仅激活客户涉及的部分，不要求填完全部指标。题目预写，模型只选题和填空；未定义需求不能临时发明指标。新增利润增速改善与同比扭亏分别表示不同语义，不拿同比为正冒充加速。

仅2026-11-09的3只iFinD样本有PE和总市值缓存。其他指标、样本外股票、不同日期均unknown。all：有fail则fail，否则有unknown则unknown，否则pass。any：有pass则pass，否则有unknown则unknown，否则fail。指数成分没有数据时明确拒绝，不能给空池成功。

行业平均、中位数、百分位与混合嵌套逻辑没有实现；未映射要求保留原话并澄清。同一快照重筛可以比较状态变化；不同快照不把数据变化归因为条件变化。

## 状态与兼容

会话保存在内存，重启会失效。历史策略文件仍保留；保存、载入、手工编辑和底层直接筛选接口仅兼容，不是当前页面流程。chat-controller.cjs的历史关键词/固定话术不参与当前/chat；每轮业务文字和选择都通过模型。

密钥只在后端。每进程模型请求上限由LLM_MAX_CALLS配置（默认20）；工具循环中的每次请求也计入。金融数据从已核对缓存读取，不因聊天自动刷新。模型或供应商错误明确显示，不回退成伪造回答/行情。

## 自然选项与校验衔接修复（2026-11-10）

下限/上限映射为gte/lte，明确高于/低于仍为gt/lt；总市值可接受原数额或精确人民币元，统一归一，不能把报告年份或PE倍数借作金额。支持明确中文季度/日期转成规范形式。行业景气与公司营收分开：没有行业指标时先征求是否采用公司层面替代，不声称有行业景气默认。

原话依据字段被拒绝时，服务端以未污染的原会话及结构化错误为上下文，让模型纠正一次；不是网络重试。每个纠正请求照常计入调用额度。第二次仍失败就整轮回滚，保留原条件；不把模型格式/单位问题归咎于客户。

## 执行结果和解释的故障隔离（2026-11-10）

评估器完成后，results不再依赖模型解释成功。金额按元/万元/亿元/万亿元生成精确可比表示；条件用screen:criteria引用，允许50000000000元展示为500亿元、小数末尾0变化。错误解释的文本不显示，允许在原有4轮总上限内纠正一次。仍失败/超时则返回真实结果与explanation.status=unavailable，HTTP200并给出单独重新生成解释入口。

单独重试读取当前会话已完成结果，使用explanation.md，1次模型请求、0次工具/金融请求；不重新计算或改变入选状态。修改条件后先重新确认筛选，不能借旧结果重试解释。未通过模型run_screen调用就没有结果时仍明确失败，不降级成伪造股票结果。
